Passwort für den Lehrkraft-Bereich setzen

Diese Seite rechnet nur hier im Browser. Nichts wird gesendet oder gespeichert.

  1. Neues Passwort eingeben. Der Hash erscheint darunter.
  2. In js/passwort.js die Zeile export const PASSWORT_HASH = '…'; suchen und den Hash zwischen die Anführungszeichen setzen.
  3. Speichern, committen, auf GitHub hochladen. Ab dann gilt das neue Passwort.
